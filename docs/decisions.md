# 決策紀錄

- 2026-10-12:官網歷史開獎 CSV 約每月更新一次,資料會落後。F1.3 自動更新不能只靠該 CSV,需另找即時來源(待查)或靠手動輸入近期期數,月初再用官方 CSV 校正。

- 2026-10-12:自動更新改用官網公開 JSON 介面(見 PRD 第 9 節),不靠每月才更新的 CSV。抓取邏輯用 JS 寫(`js/data/official.js`),瀏覽器「從官網更新」與 `tools/fetch_latest.mjs`(Actions 用)共用同一份,取代 PRD 原訂的 `fetch_latest.py`。
- 2026-10-12:API 抓到的資料寫入 `history/api/<遊戲>_api.csv`(官方 CSV 格式),`build_json.py` 先處理 api/manual 再處理官方 CSV,同期別以官方 CSV 為準。與既有資料同期別但號碼不同時視為衝突,Actions 不 commit、等人工確認。
- 2026-10-12:大樂透特別號是開獎附加號,投注時不選,所以「第二區/特別號配方」只對威力彩第二區有意義。
- 2026-10-12:回測的統計檢定以超幾何分布的理論平均與變異數做 z 檢定,並在全策略比較時提醒多重比較問題。

- 2026-10-12:參考 5 個外部 repo(`book/`,分析在 `book/analysis/`)後,只採用:抓取重試與指數退避、workflow 的 `concurrency`/`timeout-minutes`、冷熱 z-score、拖牌、AC 值/質數個數。不採用:綜合評分、強制輪替、事後回推獎項、付費牆/LINE/金流、Google Sheet 與 HTML 爬蟲。`book/` 加入 `.gitignore`(內含他人 repo)。
- 2026-10-12:選號頁的「回測組合」按鈕由 `tools/preset_search.mjs` 產生(前半段歷史挑、後半段歷史驗證),介面上同時顯示訓練段與測試段成績,避免把事後挑出的好成績呈現成優勢。

- 2026-10-13:新增「加州539」(California Fantasy 5,39 選 5,每天開獎)為第四個遊戲。上游調查:加州彩券官網 calottery.com 擋台灣 IP(瀏覽器與程式都 403),但在 GitHub Actions(美國)可連;其開獎介面 `/api/DrawGameApi/DrawGamePastDrawResults/10/{頁}/{每頁≤50}` 只開放最近約 182 期,翻頁取不到更早的,官網也沒有 CSV 下載(「download-numbers」網址只是幸運號碼查詢頁)。沒有 data.ca.gov / Kaggle 等公開資料集。決策:每日更新只用官網介面(1 次請求,不爬第三方網頁);2010-04-06 起的歷史用 lottery.net 年度存檔一次性回補,寫入前必須與官網重疊的 182 期逐期一致(實測 0 筆不一致),9800 樂透堂只在人工驗證時用。期別用開獎日期 YYYYMMDD(官方期號只取得到近半年,往前推算沒有依據)。已知缺口:lottery.net 2011~2015 年約 10 天沒有資料(2011-04-18、2011-08-12/13/27、2011-10-15、2012-05-12/13、2012-06-30、2015-01-03、2015-05-03)。金額以美元顯示,每注 US$1(未經使用者確認)。
- 2026-10-13:選號頁 539 類(今彩539、加州539)「增加號碼」除 +1/+2 外可自訂 +3~+10(最多 15 個號碼,3003 注);大樂透/威力彩維持 +1/+2。配方來源新增「尾號?」(指定尾數 0-9,可依最多次/最少次/遺漏最久/隨機排序)與「加州539(最新一期)」(加州539 分頁顯示為「今彩539(最新一期)」);名稱照使用者的寫法;這兩個來源只給主號配方,不進特別號/第二區,也不進回測組合搜尋(preset_search 只用 BASE_SOURCES),所以既有三個遊戲的回測組合與排名檔未變動。

- 2026-10-14:全系統審核後修正 14 項(清單見 HANDOFF §6.5)。決策:(1) update-data 的台灣與加州抓取互相隔離,一邊失敗不擋另一邊發布,但整個工作仍標示失敗以寄通知;(2) 期數缺漏只通知、不擋已驗證資料的發布;(3) 回測「引用另一遊戲最新一期」一律用被預測那期開獎日「之前」(不含當天)的資料,寧可保守也不洩漏未來;(4) 配方條目自訂範圍以完整歷史為準,不受全域範圍/回測窗口限制;(5) 網頁冒煙測試用 DevTools 協定直接驅動 Chrome,不引入 npm 套件(專案維持無 build、無依賴)。
